Instalación paso a paso

Android se instala en un minuto y Windows con un asistente. En Linux basta un comando; en iOS hace falta un ordenador y firmar la app con tu Apple ID.

Android

APK · 21 MB · Android 8.0 o posterior

  1. Descarga el APK desde el botón de arriba y espera a que termine la descarga.
  2. Abre el archivo. Si Android bloquea la instalación, entra en Ajustes → Seguridad y permite instalar apps desconocidas para tu navegador o gestor de archivos.
  3. Pulsa Instalar y abre TuxMusic. Si ya tenías otra versión con una firma distinta, desinstálala primero.
El APK se distribuye directamente desde dStudios, no desde Google Play. Es normal que Play Protect muestre un aviso la primera vez.

iPhone / iPad

IPA sin firmar · 1.8 MB · iOS 17 o posterior

  1. Descarga el IPA en un ordenador (Windows o Mac). No lo abras desde Safari en el iPhone.
  2. Instala Sideloadly o AltStore en el ordenador.
  3. Conecta el iPhone, confía en el equipo y arrastra el IPA a la herramienta.
  4. Introduce tu Apple ID y firma. Después activa Ajustes → Privacidad y seguridad → Modo de desarrollador y confía en el desarrollador en VPN y gestión de dispositivos.
  5. Con una cuenta gratuita la app funciona 7 días; vuelve a firmarla para renovarla. Con una cuenta Apple Developer de pago puedes usar TestFlight o Ad Hoc.
El IPA no está firmado por Apple. No se puede instalar abriéndolo desde el iPhone: necesita Sideloadly, AltStore o Xcode con un Mac y una cuenta Apple.

Linux

.deb · 5.4 MB · amd64 · Debian 13+ / Ubuntu 24.10+

  1. Descarga el .deb desde la tarjeta de Linux.
  2. Abre una terminal en la carpeta de descargas y ejecuta sudo apt install ./TuxMusic-Linux-1.3.1.deb. apt instala también GTK4, libadwaita y GStreamer.
  3. Abre TuxMusic desde el menú de aplicaciones o ejecuta tuxmusic-rust en una terminal.
  4. Para desinstalarlo: sudo apt remove tuxmusic. Tus datos personales no se borran.
El paquete está compilado para amd64 y necesita glibc 2.39 o posterior. En distribuciones más antiguas, compila desde el código fuente con install.sh.

Windows

Instalador .exe · 121 MB · Windows 10 y 11 de 64 bits

  1. Descarga el instalador desde la tarjeta de Windows.
  2. Ejecuta el archivo. Si SmartScreen muestra una advertencia, pulsa Más información → Ejecutar de todas formas.
  3. Sigue el asistente y elige la carpeta de instalación. Se crea un acceso directo en el menú Inicio.
  4. Abre TuxMusic. La primera vez, permite el acceso a la red para buscar carátulas y canciones.
El instalador no está firmado digitalmente. Descárgalo únicamente desde esta página y verifica su SHA-256 antes de ejecutarlo.
